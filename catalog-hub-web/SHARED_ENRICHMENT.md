# Поиск источников Catalog Hub

Catalog Hub самостоятельно ищет официальный сайт бренда и страницу товара по бренду, SKU и названию. Он загружает страницу на своём сервере, проверяет совпадение SKU, бренда и фасовки, извлекает описание, применение, состав и кандидатов фотографий. `OPENAI_API_KEY` нужен для поиска в сети и подготовки текста по фактам страницы. При прямой ссылке на товар извлечение работает без ключа. Другие магазины используются только если оператор включил дополнительный поиск.

Результат является предложением. Оператор выбирает поля и фото, проверяет ссылку и фасовку, затем утверждает изменения в Catalog Hub. Магазин получает только утверждённые карточки через отдельную интеграцию выгрузки.

В окружении Catalog Hub задайте `OPENAI_API_KEY`. Для локального запуска можно добавить его в `catalog-hub-web/.env.local`. Поиск не требует адреса или секрета ProCosmetics.
