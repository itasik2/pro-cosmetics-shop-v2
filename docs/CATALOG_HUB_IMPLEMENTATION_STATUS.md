Проверены PDF.js и предпросмотр через браузерный Next.js интерфейс. Из каждого файла одна выбранная строка создана в изолированной БД с явно назначенными ценовыми колонками: собственный запас остался нулевым, повтор со старым fingerprint отклонён.

В отдельном прогоне через очередь созданы 151 из 172 строк Skinosophy с исходным артикулом и двумя числовыми ценами. Для каждой проверены закупочная и розничная цены, нулевой запас и единственная попытка применения. Повтор обработки завершённой очереди вернул ноль обработанных строк. Остальные строки из четырёх файлов требуют сверки артикула, двух цен или назначения единственной суммы. Роли цен в этом прогоне заданы для тестового контура.

## Оставшиеся этапы

1. **P0:** сверка неподтверждённых строк. Все 19 спорных строк Skinosophy не имеют числовой розницы, две другие строки конфликтуют по артикулу. Фото проверены на четырёх реальных вариантах с двух сайтов. Требования к разрешению использования фотографий и согласованию спорных данных сохраняются.
2. **P1:** базовое складское ядро, отдельные резервы, сверка, лимиты очереди и восстановление import worker реализованы и проверены изолированно. Перед боевым cutover остаются разбор старых непривязанных резервов и проверка восстановления на целевой инфраструктуре.
3. **P2:** подготовлены per-recipient доставка, подписанные подтверждения, SDK inbox, диагностика и OpenAPI. Остаются контракт остальных операций адаптеров, сверка результата применения и нагрузочная проверка десяти получателей; отдельный репозиторий не создаётся без плана переноса.
4. **P3:** shadow diff реальных ProCosmetics Product/Variant/Order и включение подписанных событий в самом магазине, выборочный cutover и проверенный rollback. Рабочий канал защищён от случайного включения.
5. **P4:** доступ владельца к одному магазину Kaspi, read-only инвентаризация полного набора офферов, сопоставления, подтверждённая загрузка и статусы. Подготовленный XML не доказывает, что Kaspi его принял.
6. **P5:** связать существующий безопасный репрайсер с канальными предложениями, финальная проверка маржи непосредственно перед публикацией, разрешённые источники конкурентов и выключатель.
7. **P6:** пользователи, роли, приглашения, регистрация второй организации, лимиты и SaaS-биллинг. Ключ API и OIDC не заменяют вход сотрудников.
8. **P7:** рабочие Ozon/Wildberries адаптеры после пилотов. Пока возвращается UNSUPPORTED, а не фиктивный успешный результат.
